Dataanalysprojekt – Gröna Gården (KPI och kunddata)

Rensade och strukturerade ett dataset (2399 orderrader) där datum, priser och vikt initialt var feltypade som text
Byggde en ETL-pipeline i Python/pandas som normaliserade datumformat, produktnamn och kategorier, och hanterade saknade värden per kolumn
Beräknade leverans-KPI (leveranstid) och löste datakvalitetsproblem som orsakade orimliga resultat
Genomförde sentimentanalys av 1038 kundrecensioner med en BERT-modell, inklusive validering mot ett separat testset
Lagrade resultat i en SQL-databas och drog affärsinsikter om leveranszoner, produktkategorisering och förpackningskvalitet
